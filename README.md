## 🌟 Features

- **End-to-End RAG Ingestion Pipeline**: Clones public or authenticated GitHub repositories, filters code files, generates AST/sliding-window chunks, and produces dense vector embeddings.
- **Hybrid Retrieval (Dense + Sparse)**: Blends semantic similarity via **Qdrant** with keyword frequency matching via **Whoosh BM25** to accurately locate symbols, logic, and configurations.
- **Strictly Grounded Citations**: Answers generated by **FLAN-T5** (`google/flan-t5-base`) cite exact file paths and line ranges with interactive previews.
- **100% Free & Open-Source AI Stack**: Runs completely free with Hugging Face models (`sentence-transformers/paraphrase-MPNet-base-v2` and `google/flan-t5-base`), requiring zero paid OpenAI/Anthropic API keys.
- **Secure GitHub OAuth Authentication**: Sign in with GitHub to access repository indexation and querying.
- **Modern Responsive UI**: Clean, responsive developer interface crafted with React 18, Vite, TypeScript, and Tailwind CSS.
- **Production Containerization**: Fully reproducible multi-container deployment powered by Docker Compose.

## 🚀 Quick Start with Docker Compose

The fastest way to launch the complete RepoMind stack (Qdrant + Backend + Frontend):

### 1. Clone the repository and prepare `.env`

```bash
git clone https://github.com/Krish-megabytes/RepoMind.git
cd RepoMind
cp backend/.env.example backend/.env
```

Edit `backend/.env` with your GitHub OAuth app credentials:
```env
GITHUB_CLIENT_ID=your_github_client_id
GITHUB_CLIENT_SECRET=your_github_client_secret
GITHUB_REDIRECT_URI=http://localhost:8000/auth/callback
QDRANT_HOST=qdrant
QDRANT_PORT=6333
```

### 2. Launch all services

```bash
docker compose up --build
```

Access the services:
- **Frontend Web UI**: [http://localhost:3000](http://localhost:3000)
- **FastAPI Documentation**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **Qdrant Dashboard**: [http://localhost:6333/dashboard](http://localhost:6333/dashboard)

## 💻 Local Development Setup

### Prerequisites
- Python 3.11+
- Node.js 20+ & npm
- Docker (for Qdrant vector store)

### 1. Start Qdrant

```bash
docker run -p 6333:6333 -p 6334:6334 \
    -v $(pwd)/qdrant_storage:/qdrant/storage:z \
    qdrant/qdrant
```

### 2. Backend Setup

```bash
cd backend
python -m venv .venv

# On Linux / macOS:
source .venv/bin/activate
# On Windows:
.venv\Scripts\activate

pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### 3. Frontend Setup

```bash
cd ../frontend
npm install
npm run dev
```

The frontend will run on [http://localhost:5173](http://localhost:5173) and proxy or request the backend on port 8000.

## 📡 API Reference

| Method | Endpoint | Description | Auth Required |
|---|---|---|---|
| `GET` | `/health` | Health check endpoint | No |
| `GET` | `/auth/login` | Redirects to GitHub OAuth authorization | No |
| `GET` | `/auth/callback` | Exchanges code for access token | No |
| `POST` | `/ingest` | Clones and indexes a GitHub repository | Yes |
| `POST` | `/query` | Hybrid search query with cited AI answer | Yes |
| `GET` | `/repos` | List all ingested repository collections | Yes |
| `DELETE` | `/repos/{name}` | Delete repository collection from index | Yes |
